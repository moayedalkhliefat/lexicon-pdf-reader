# Lexicon — PDF Reader & Arabic Translator

Read any PDF in the browser. Double-click a word to see its Arabic translation and English meaning, or select a sentence to translate it into Arabic. Students sign in with their name; saved words, flashcards and progress are stored online. Teachers get a PIN-protected dashboard.

**Live:** https://moayedalkhliefat.github.io/lexicon-pdf-reader/

Designed by **Mr. Moayed Alkhliefat**.

Built with PDF.js, the Free Dictionary API, MyMemory / Google Translation, and Supabase.
