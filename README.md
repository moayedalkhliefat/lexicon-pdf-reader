# Lexicon — PDF Reader & Arabic Translator

Read any PDF in the browser. Double-click a word to see its Arabic or Chinese translation (simplified, with pinyin) and English meaning, or select a sentence to translate it. Chinese text in a PDF is translated into English or Arabic (student's choice). Each student can open a limited number of files, and only the first pages of long files are shown; the teacher sets both limits. Students sign in with their name; saved words, flashcards and progress are stored online. Teachers get a PIN-protected dashboard.

**Live:** https://moayedalkhliefat.github.io/lexicon-pdf-reader/

Designed by **Mr. Moayed Alkhliefat**.

Built with PDF.js, the Free Dictionary API, MyMemory / Google Translation, pinyin-pro, and Supabase.
